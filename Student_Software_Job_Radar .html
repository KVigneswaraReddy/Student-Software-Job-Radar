What should students prepare?

  • C programming, Java or Python fundamentals
  • Data Structures and Algorithms (arrays, strings, linked lists, stacks, queues, trees, sorting and searching)
  • OOP, DBMS, SQL, Operating Systems and Computer Networks
  • Problem solving on practice platforms and timed coding assessments
  • Resume, projects, communication and interview preparation

Common recruitment procedure

  1. Online application and eligibility screening
  2. Aptitude, reasoning and/or technical assessment
  3. Coding test or technical interview
  4. Technical and managerial interview rounds
  5. HR discussion, document verification and offer

Stages differ by employer, role, country and recruitment drive.

Common recruitment procedure

  1. Online application and eligibility screening
  2. Aptitude, reasoning or communication assessment (where applicable)
  3. Programming / coding assessment or technical test
  4. Technical interview(s), project discussion or practical round
  5. HR discussion, document verification and offer

The sequence and number of rounds vary by employer, role, location and hiring programme.

Before clicking Apply

  • Confirm that the vacancy is currently open on the official employer website.
  • Check graduation year, branch, marks/CGPA and backlog criteria.
  • Review the job description, location, work mode and application deadline.
  • Use the official application page and never pay a recruitment fee.
